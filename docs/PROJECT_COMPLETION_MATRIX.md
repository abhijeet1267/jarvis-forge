# VANTAGE — Project-Completion Matrix

Evidence-based completion tracking per the completion directive. States (per the
directive's release-readiness rubric):

- **NOT IMPLEMENTED** — no code for the feature.
- **IN PROGRESS** — code partially written, not coherent yet.
- **IMPL-UNTESTED** — code written, no meaningful test.
- **UNIT TESTED** — deterministic tests pass; not exercised end-to-end.
- **INTEGRATION TESTED** — cross-component tests pass.
- **RUNTIME VERIFIED** — observed on the live process/UI, not just in tests.
- **RELEASE READY** — build + tests + runtime verified, docs match.
- **EXTERNALLY BLOCKED** — needs owner permission / hardware / external service; work
  around it is done, the final step is blocked (each names the minimum unblock).
